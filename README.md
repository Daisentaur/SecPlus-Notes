# Security+ Notes

My notes working through the CompTIA Security+ syllabus, written in my own words as I go through the motions.

Not exam prep — an industry contact pointed me at the curriculum as solid groundwork for getting into security, and I'm building from near-zero on networking and security.

Notes follow the course chapter structure. Each file works through the concepts with my own examples and reasoning rather than restating the lectures.
